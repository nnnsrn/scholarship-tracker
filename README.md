# 🎓 Master's Scholarship Tracker

A personal web application for managing Master's degree and scholarship applications in one place.

The goal is simple: keep programs, requirements, documents, language tests, recommendation requests, deadlines, and application progress organized throughout the application cycle.

## ✨ Features

### 📊 Application Dashboard
- Overview of all tracked Master's programs
- Application status summary
- Upcoming application deadlines
- Deadline urgency indicators
- Today's priorities
- Items requiring attention
- Application pipeline overview

### 🎓 Program Management
- Add, edit, and delete Master's programs
- Track university, program, location, degree, funding, and application information
- Track application status and priority
- View individual program details
- Track application readiness

### ✅ Requirements & Checklists
- Track required and optional application requirements
- Mark requirements as completed or pending
- Link documents to specific requirements
- Filter requirements by status
- Monitor overall application readiness

### 📄 Document Management
- Maintain a personal document library
- Track documents used for applications
- Link documents to application requirements
- Store document metadata such as type, version, and file size

### 🌐 Language Tests
- Track IELTS and other language test attempts
- Record test dates and scores
- Keep language test information organized for applications

### ✉️ Recommendation Tracking
- Maintain a list of recommenders
- Track recommendation requests
- Monitor request status and deadlines

### 📅 Calendar & Timeline
- View application deadlines and important events
- Track application-related dates in one place

### 💾 Data Backup
- Export application data as JSON
- Import previously exported data
- Local-first data persistence using browser storage
